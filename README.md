# Breakout em C com Raylib

Um projeto acadêmico do clássico jogo Breakout, desenvolvido inteiramente em C com a biblioteca gráfica Raylib.


## 🔧 Como Compilar e Rodar

O projeto utiliza `make` para compilação em ambiente Linux.

1.  **Clone o repositório**
2.  **Instale a biblioteca Raylib** (o `Makefile` espera encontrá-la em `/usr/local/lib`)
3.  **Compile e rode:**
    ```bash
    make run
    ```
4.  **Limpe os arquivos de build:**
    ```bash
    make clean
    ```
